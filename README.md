# Эрита — финансовый наставник

Прототип мобильного веб-приложения — личный финансовый наставник для женщин 30–55 лет. Диагностика финансов, персональная карта, модули психологии денег, дисциплины, бюджета, активов и стратегии (кредиты, ипотека), цели, план внедрения и коуч-чат.

Подробное описание продукта — в [PRD.md](./PRD.md).

## Стек

React 19 + TypeScript + Vite + React Router (Hash) + Zustand (persist) + Tailwind CSS.

Все финансовые расчёты (погашение кредитов, ипотека, бюджет) — детерминированный код, без обращения к LLM. Данные хранятся локально в браузере (localStorage), бэкенда нет.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

При пуше в `main` GitHub Actions автоматически собирает проект и публикует его на GitHub Pages.
